## 글 구조 (관점 통합 6단)

기능별 22개 글의 6단 구조를 변형하여 사용한다.

1. **관점 정의** — 이 축에서 시스템을 본다는 게 무엇이고 왜 중요한가
2. **전체 흐름도** — 이 글이 다루는 단계 전체의 텍스트 다이어그램
3. **단계별 핵심** — 단계마다 (a)무엇이 일어나는가 (b)어느 코드가 책임지는가 (c)관련 기능 # 링크
4. **기능 글로의 진입점** — 본 시리즈에서 다룬 기능 → `docs/blog/NN_*.md` 직접 링크 표
5. **통합 설계 트레이드오프** — 이 축 전체로 봤을 때만 보이는 결정·약점·미구현 영역
6. **한 줄 정리** — TL;DR

기능별 글과의 차이: **코드 인용은 단계당 1~2개로 줄이고, 대신 기존 22개 글로의 링크가 본문의 척추**가 된다.
